📋 The Flow
1. Recruiter uploads resume via React frontend
2. FastAPI stores file in Blob Storage
3. Document Intelligence extracts text + structure from the PDF
4. OpenAI embeddings vectorize the content
5. AI Search indexes it for keyword + semantic queries
6. When a job is posted, GPT-5.2 ranks matching candidates
7. AI Foundry Agent can run full multi-step screening autonomously
8. Results stored in PostgreSQL, displayed in the frontend
